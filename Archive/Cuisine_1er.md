
# Cuisine du 1er : fin le 5 novembre 


 - Se concentrer sur ce qu'on voit en premier 
 - On encoller le mur plutôt que les carreau, sauf pour le petit/coupé : la c'est le dos du carrelage 
 - Le double encollage est pour les grand carreaux 
 - La taille des dents est en fonction du carrelage 
 - Gratter la ou la colle dépasse au cutter 
 - Il faut placer des tasseaux horizontaux *ET verticaux* pour delimiter les dernières rangés entière : lorsqu'on enlève les tasseaux il reste plus qu'à couper le carrelage pour le mettre aux emplacements (particulièrement utile pour les sols pas droits).  On part du bas et on remonte 
 - Conseil de l'autonivelant pour le sol
 - Bien tout tracer avant de se lancer 
 - Bien faire le niveau entre les carreaux et vérifier régulièrement 
 - Faire le sol et après mur 

Étapes joints :
    1. Pâtes souple, relativement liquide (yaourte) 
    2. Mettre avec la raclette noire (en diagonale avec un petit mouvement rotatif du poignet)
    3. Ajuster les zones avec la langue de chat 
    4. Gratter avec crayon/embout glace 
    5. Utiliser la taloche éponges 
    6. Utiliser l'eponge
